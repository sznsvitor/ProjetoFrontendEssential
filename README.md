# 🌦️ Weatherly — Projeto Final Front-End

> **Serratec Residência em TIC · Sala 34 · Trabalho Final - Front-End Essencial**

---

## 📌 Sobre o Projeto

O **Weatherly** é uma aplicação web desenvolvida pelo **Grupo 3** como projeto final da disciplina de **Front-End Essencial** do programa **Serratec/Residência em TIC**.

O projeto tem como objetivo fornecer informações climáticas em tempo real de qualquer cidade do mundo, utilizando integração com API de clima, interface moderna e experiência dinâmica para o usuário.

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- OpenWeather API

---

## 🌍 Acesse o Projeto

🔗 Site publicado:  
https://weatherly2026.netlify.app/pages/mainpage

---

## ✨ Funcionalidades

- 🔎 Pesquisa de clima por cidade
- 🌡️ Exibição de temperatura atual
- ☁️ Informações climáticas em tempo real
- 🌧️ Fundo dinâmico com GIFs conforme o clima
- 📱 Layout responsivo
- 🎨 Interface moderna e animada
